SiS Publisher — Privacy Policy

SiS Publisher is a private tool used only by the owner of the YouTube channel "SiS" (@someinterestingstories) to upload and schedule the owner's own videos, set thumbnails, post the first comment and read the channel's own analytics.

Data accessed

Only the owner's own YouTube channel data, through the YouTube Data API and YouTube Analytics API, after the owner signs in with Google OAuth.

Storage and sharing

The OAuth token and downloaded statistics are stored only on the owner's personal computer. No data is sold, shared with third parties, or used for advertising.

Other users

The app is not offered to the public. Anyone who signs in would only grant access to their own account, and no data would be collected or stored from them.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
